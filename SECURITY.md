# Security policy

## Supported versions

Security fixes are released for the latest version.

## Reporting a vulnerability

Please don't open a public issue. Email **atoausten@duck.com** instead, with:

- what the problem is and what an attacker could do with it
- steps to reproduce it, or a proof of concept
- the Kinetics version, and your Filament, Laravel and PHP versions

You'll get a reply within a few days. Once a fix is released, the changelog
will credit you, unless you'd rather stay anonymous.

Kinetics is a theme: it adds CSS, a font, icons and panel settings. If the
problem is in Filament itself, report it to
[Filament](https://github.com/filamentphp/filament/security/policy) as well.
